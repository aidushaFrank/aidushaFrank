## Featured Project

### [BlueBoat Telemetry Dashboard](https://github.com/aidushaFrank/blueboat-telemetry-dashboard)

A data pipeline and dashboard for exploring telemetry and sonar data collected by an autonomous surface vehicle used in marine field research.

- **What I built:** Tools for importing, cleaning, synchronizing, and replaying GPS, vehicle telemetry, and sonar depth data
- **Tech stack:** Python, InfluxDB, Grafana, Docker, MAVLink, and QGroundControl logs
- **Why it matters:** Makes field data easier to review through maps, depth visualizations, and vehicle performance metrics

- **Tech stack:** HTML, CSS, JavaScript, and Chrome extension APIs
- **What I learned:** Building a browser extension from scratch, collaborating through GitHub branches, and resolving merge conflicts as a team
